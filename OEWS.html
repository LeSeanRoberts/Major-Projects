Abstract

This study leverages the New York State Occupational Employment and Wage Statistics (OEWS) dataset to model and predict median annual wages across diverse labour sectors. Initial Exploratory Data Analysis (EDA) and visualisation revealed significant wage disparities. K-Means clustering was evaluated to identify latent structural groupings within the labour market, while extensive feature engineering—including the extraction of SOC Major Groups, Credential Proxies, and a Cost-of-Living (COL) Index—was implemented to provide essential economic context; applied to random forest. The results demonstrate that incorporating hierarchical occupational structures is vital for mitigating prediction anomalies in heterogeneous labour data.

Introduction

This study utilizes the Occupational Employment and Wage Statistics (OEWS) dataset published by the New York State Department of Labour to examine and predict median annual wages across diverse labour sectors in New York State. Given the multidimensional and heterogeneous nature of occupational labour data—spanning industries, geographies, and skill levels—a structured analytical framework is required to uncover patterns, contextualize disparities, and build reliable predictive models.

Exploratory Data Analysis (EDA) and visualiation constitute the first stage of this framework. Distributional plots, comparative wage summaries, and regional or occupational breakdowns provide an immediate view of wage dispersion, outliers, and structural inequalities across sectors. These techniques help diagnose skewness, heteroscedasticity, and occupational concentration effects, while guiding data cleaning and transformation decisions. By revealing the underlying structure of the dataset, visualization ensures that subsequent modeling steps are both statistically grounded and interpretable.

To further investigate latent structure within the labour market, K-Means clustering is employed as an unsupervised learning approach. Clustering groups occupations or regions with similar employment and wage characteristics, enabling identification of natural segments such as high-skill/high-wage occupations, transitional middle-skill clusters, and lower-wage service sectors. These groupings provide insight into structural segmentation and serve as an empirical basis for understanding heterogeneity before predictive modelling.

Complementing this exploratory phase, Random Forest modelling is applied to predict median annual wages using both raw variables and engineered features. Feature engineering plays a critical role, incorporating hierarchical Standard Occupational Classification (SOC) Major Groups, credential proxies, and a Cost-of-Living (COL) index to embed economic and institutional context into the model. Random Forest’s ensemble structure captures nonlinear relationships and complex interactions while providing variable importance measures that clarify the drivers of wage outcomes. This approach enhances predictive robustness and mitigates anomalies arising from diverse occupational categories.

Together, visualization, clustering, and ensemble learning create an integrated pipeline that transforms OEWS data into both explanatory insights and reliable wage forecasts.

Based on the data dictionary and the Occupational Employment and Wage Statistics (OEWS) dataset referenced, the Standard Occupational Code (SOC) is a hierarchical system.

The SOC code is a 6-digit code (often displayed with a hyphen, e.g., 11-1011). The labels for each value depend on the level of the hierarchy you are looking at.

Hierarchy Labels (The Tiers)

Each part of the 6-digit code represents a specific level of detail. The labels for these “tiers” are:

  • Major Group: The first two digits (e.g., 11-0000). These are the broadest categories (e.g., Management, Healthcare).

  • Minor Group: The third digit (e.g., 11-1000).

  • Broad Occupation: The fourth and fifth digits (e.g., 11-1010).

  • Detailed Occupation: The sixth digit (e.g., 11-1011). This is the most specific level used in the dataset.

Occupational Title

Unlike the area_type, which has only two distinct values, the occupational_title labels are dynamic and correspond directly to the Standard Occupational Code (SOC).

  • Total Labels: There are approximately 821-830 unique labels in this field.

  • Definition: This field contains the text name for the job category. It follows the federal 2018 SOC system (though some older data may use the 2010 system).

  • Format: These are the common names for jobs.

Examples of Labels in this field:

  • Chief Executives (for SOC 11-1011)

  • General and Operations Managers (for SOC 11-1021)

  • Registered Nurses (for SOC 29-1141)

  • Software Developers (for SOC 15-1252)

To reduce the excessive granularity of the occupational_title column, willuse the Standard Occupational Code (SOC) column. The detailed occupations provided in the dataset are based on the 2010 Standard Occupational Classification (SOC) system. The SOC structure is hierarchical, meaning one can aggregate the detailed titles into broader categories by taking the first two, four, or six digits of the code. To reduce the 729 unique instances down as far as possible, while keeping all other attributes relevant…will aggregate the data based on the Major Group level of the SOC system.

# Data that's meaningful for EDA, supervised and unsupervised learning interests 
OEWS_for_modelling <- OEWS_data_clean |>
  # 1. Create the high-level group column
  mutate(major_group_code = substr(standard_occupational_code, 1, 2)) |>
  
  # 2. Keeping the necessary columns for future research
  select(
    area_type, 
    area, 
    area_name, 
    occupational_title,
    major_group_code, # New reduced granularity column
    employment, 
    mean, 
    median, 
    entry_wage, 
    experienced_wage
  ) |>
  
  # 3. Optional: Convert the new code to a factor for modeling
  mutate(major_group_code = as.factor(major_group_code))

Generating Q-Q Plots

A Quantile-Quantile (Q-Q) plot is a graphical tool used to decide if a dataset follows a specific theoretical distribution. Instead of just observe a histogram or kernel density and judging if it looks good enough to be represented by the theoretical distribution in question, a Q-Q plot gives a precise line to follow. The plot compares two sets of quantiles against each other:

  1. The Theoretical Quantiles: Where your data should fall if it followed a specific distribution (like the Normal Distribution).

  2. The Sample Quantiles: Where your data actually falls.

Each data point from the sample is paired with a corresponding quantile from the theoretical distribution and plotted on a scatter plot. One to then observe how well the points hug a 45-degree reference line.

Q-Q plots for numeric (continuous) attributes:
Observation Interpretation
Points follow the line The data follows the assumed distribution (e.g., it is normal).
Curved “S” shape The data has “fats tails” (kurtosis) or is more skewed than the distribution.
Points curve up or down The data is skewed to the left or right.
Significant outliers Points at the very ends of the plot will stray far from the line.

For correlation, choice of measure will be Spearman, which measures any monotonic relationship between two continuous random variables and is adopted when the data do not follow a normal distribution (Rovetta, 2020).

Spearman Correlation:

A measure of monotonic relationship based on ranks.

Instead of using the raw data values (\(X_i, Y_i\)), we convert them into ranks (\(R_i, S_i\)).

  • \(X_i\): Raw value for observation \(i\) in variable 1.

  • \(Y_i\): Raw value for observation \(i\) in variable 2.

  • \(R_i\): Rank of \(X_i\) (e.g., 1 for smallest, \(n\) for largest).

  • \(S_i\): Rank of \(Y_i\).

Spearman’s correlation is calculated by applying the Pearson correlation formula to the ranks:

\[ \rho = \frac{\text{cov}(R,S)}{\sigma_R \sigma_S} \]

Where:

  • \(\text{cov}(R, S)\) is the covariance of the ranks.

  • \(\sigma_R\) and \(\sigma_S\) are the standard deviations of the ranks.

The Simplified Formula (for no ties):

If there are no tied ranks (every data point has a unique value), the formula simplifies to a much faster version based on the difference between ranks (\(d_i = R_i - S_i\)):

\[ \rho = 1 - \frac{6\sum{d_{i}^2}}{n(n^2-1)} \]

Where:

  • \(d_i\): The difference between the rank of \(X_i\) and the rank of \(Y_i\).

  • \(n\): The number of observations.

Key Mathematical Characteristics:

Characteristic Description
Range \(-1 \leq \rho \leq 1\)
Interpretation

+1: Perfect monotonic increasing relationship.


-1: Perfect monotonic decreasing relationship.


0: No monotonic relationship.
Robustness Because it uses ranks, it is highly robust to outliers in the raw data.
Data Type Ideally suited for ordinal data, but also used on continuous data to check for non-linear, monotonic trends.

Observed:

  • One categorical variable with two levels (say type ∈ {A, B})

  • Non-normal continuous variable (employment, etc., etc.)

This is exactly the classical setting for the Mann–Whitney U test (Hinton, 2010), also called the Wilcoxon rank-sum test).

Data structure for such test:

Let

\[ T_i \in \{0,1\}, i=1,...,N \]

be the binary group indicator.

Have

\[ E_i \in \mathbb{R} \]

as the continuous outcome.

Split into groups:

\[ X=\{E_i : T_i = 0\}, n_1 = |X| \]

\[ Y=\{E_i : T_i = 1\}, n_2 = |Y| \]

\[ N=n_1 + n_2 \]

Hypotheses:

Distributional –

\[ H_0: F_X(e)=F_Y(e) \longrightarrow \text{median}(X)=\text{median}(Y) \]

\[ H_1: \text{medians differ} \]

Ranking:

Pool observations –

\[ \{E_1,...,E_n\} \]

Assign ranks –

\[ R_i=\text{rank}(E_i) \]

Rank sums:

Group 0 –

\[ R_X= \sum_{i:T_i=0} R_i \]

Group 1 –

\[ R_Y= \sum_{i:T_i=1} R_i \]

Mann-Whitney statistic:

\[ U_X = R_X - \frac{n_1(n_1 +1)}{2} \]

Equivalent pairwise form –

\[ U_x=\sum_{i:T_i=0} \sum_{i:T_i=1} \textbf{1} (E_i > E_j) + \frac{1}{2}\textbf{1}(E_i = E_j) \]

Interpretation:

\[ U_X = \text{# times group 0 employment > group 1 employment} \]

Distribution under \(H_0\):

\[ \mathbb{E}[U_X]=\frac{n_1 n_2}{2} \]

\[ \text{Var}(U_X)=\frac{n_1n_2(N+1)}{12}... \text{no ties} \]

Test statistic:

\[ Z=\frac{U_X -\frac{n_1n_2}{2}}{\sqrt{\frac{n_1n_2(N+1)}{12}}}\sim \mathcal{N}(0,1) \]

Effective size:

Probability that one type has higher employment –

\[ P(X>Y)=\frac{U_X}{n_1n_2} \]

SEPARATE NOTE: the interquartile range (IQR) measures statistical dispersion by computing the spread of the middle 50% of a data set \((IQR = Q_3 - Q_1)\). It identifies the range between the 75th percentile \((Q_3)\) and the 25th percentile \((Q_1)\), making it a robust measure that ignores outliers. A smaller IQR indicates more consistent data, while a larger IQR suggests higher variability.

compare_binary_nonparam <- function(data, group, var_names){

  # checks
  if(!group %in% names(data))
    stop("Grouping variable not found in data")

  if(!all(var_names %in% names(data)))
    stop("Some variables not found in data")

  g <- as.factor(data[[group]])

  if(n_distinct(g) != 2)
    stop(paste(group, "must have exactly 2 unique values"))

  groups <- sort(unique(g))

  purrr::map_dfr(var_names, function(v){

    y <- data[[v]]

    # keep only complete cases
    idx <- !is.na(y) & !is.na(g)
    y <- y[idx]
    g_sub <- g[idx]

    # skip non-numeric safely
    if(!is.numeric(y)) return(NULL)

    wt <- wilcox.test(y ~ g_sub)
    cd <- effsize::cliff.delta(y ~ g_sub)

    g1 <- groups[1]
    g2 <- groups[2]

    tibble(
      variable = v,
      group1 = g1,
      group2 = g2,
      n1 = sum(g_sub == g1),
      n2 = sum(g_sub == g2),
      median1 = median(y[g_sub == g1]),
      median2 = median(y[g_sub == g2]),
      IQR1 = IQR(y[g_sub == g1]),
      IQR2 = IQR(y[g_sub == g2]),
      p_value = wt$p.value,
      cliffs_delta = cd$estimate
    )
  })
}

Factor vs. Factor:

Applying the Chi-squared test of independence among the categorical variables (Salkind, 2007).

Contingency Table (observed frequencies):

  • First, to organise the data into an \(r \times c\) contingency table, where \(r\) is the number of categories for Variable \(A\) and \(c\) is the number of categories for Variable \(B\).

  • Let \(O_{ij}\) represent the observed frequency (count) of observations falling into the \(i\)-th row and \(j\)-th column.

Variable B: Cat 1 Variable B: Cat 2 Row Totals (Ri​)
Variable A: Cat 1 \(O_{11}\) \(O_{12}\) \(R_1\)
Variable A: Cat 2 \(O_{21}\) \(O_{22}\) \(R_2\)
Column Totals (\(C_j\)) \(C_1\) \(C_2\) Grand Total (\(N\))

Expected Frequences:

Under the Null Hypothesis (\(H_0\)), to assume the variables are independent. If they are independent, the probability of falling into a specific cell should be the product of the marginal probabilities.

The Expected Frequency (\(E_{ij}\)) for each cell is calculated as:

\[ E_{ij}=\frac{R_i \times C_j}{N} \]

Where:

  • \(R_i\) = Total observations in row \(i\)

  • \(C_j\) = Total observations in column \(j\)

  • \(N\) = Total number of independent trips (the grand total)

The Test Statistic:

To quantify how much our observed data deviates from what we “expected” to see under independence, we use the \(\chi^2\) statistic:

\[ \chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij}-E_{ij})^2}{E_{ij}} \]

Degrees of freedom. The shape of the \(\chi^2\) distribution depends on the table’s dimensions:

\[ df=(r-1)\times(c-1) \]

Decision rule:

To determine if the relationship is statistically significant, to compare our calculated \(\chi^2\) value to a critical value from the \(\chi^2\) distribution table at a chosen significance level (usually \(\alpha = 0.05\)).

  • If \(\chi^2_{calc} > \chi^2_{crit}\): We reject \(H_0\). There is a significant association between the variables.

  • If \(p\text{-value} < \alpha\): We reject \(H_0\).

K-Means Clustering

The primary purpose of clustering is to partition unlabeled data into natural, homogeneous groups (clusters) where items in the same group are more similar to each other than to those in others. This unsupervised machine learning technique identifies hidden patterns, structures, and relationships, facilitating data segmentation, anomaly detection, and data compression

K-Means clustering (Hartigan & Wong, 1979) is an unsupervised learning algorithm that partitions data into K distinct, non-overlapping subgroups (clusters) by minimising the distance between data points and their cluster centroid.

To comprehend K-Means mathematically, view it as an optimisation problem where the objective is to minimise the “tightness” of each cluster.

For a set of independent observations \((\mathbf{x}_1,\mathbf{x}_2,…,\mathbf{x}_n)\) where each x is a vector of your numeric features (like lat, long, salinity, etc.), the algorithm abides by the following steps:

  1. The Objective Function:

The goal is to minimize the Within-Cluster Sum of Squares (WCSS), also known as Inertia:

\[ J=\sum_{i=1}^k \sum_{x \in S_i} \|\mathbf{x} - \mathbf{\mu_i}\|^2 \]

where:

\(k\) is the number of clusters.

\(S_i\) is the set of points in the \(i^{th}\) cluster.

\(\mathbf{\mu_{i}}\) is the centroid (mean) of points in \(S_i\) , defined as

\[ \mu_{\mathbf{i}}=\frac{1}{|S_i|}\sum_{x\in S_i} x \]

\(\|\mathbf{x} - \mathbf{\mu_i}\|^2\) is the squared Euclidean distance between a point and its cluster centre.

  1. The Iterative Process (Lloyd’s Algorithm):

The algorithm reaches the minimum through two alternating steps:

Step A: Assignment (Expectation) - Assign each observation to the cluster whose mean has the least squared Euclidean distance:

Step Action Mathematical Logic
1. Assignment Assign each \(x\) to the nearest cluster. \(S_i^{(t)} = \{x_j : \|x_j - \mu_i^{(t)}\|^2 \leq \|x_j - \mu_l^{(t)}\|^2 \forall l \in \{1,...,k\}\}\)
2. Update Calculate the new centroids. \(\mu_{i}^{(t+1)} = \frac{1}{|S_{i}^{(t)}|} \sum_{x_j \in S_{i}^{(t)}} x_j\)

The algorithm converges when the assignments no longer change. Because the WCSS is non-increasing at each step and there are a finite number of ways to partition the data, the algorithm is guaranteed to reach a local minimum.

Note on Independence: Because you treat each case as independent, the distance calculation for \(x_j\) relies solely on its own features and the current centroids, without being influenced by the sequence or ordering of other cases in the dataset.

Random Forest

Ensemble Methods

Ensemble learning methods are constituted by a set of classifiers—e.g. decision trees—and their predictions are aggregated to identify the most popular result (Kavlakoglu, 2025). The most popular ensemble methods are bagging, also known as bootstrap aggregation, and boosting. For the bagging method, a random sample of data in a training set is selected with replacement—the individual data points can be applied more than once. After multiple data samples are generated, these models are then trained independently, and depending on the type of task—i.e. regression or classification—the average or majority of those predictions yield a more accurate estimate. This approach is commonly used to reduce variance within a noisy dataset.

The Random Forest Algorithm

Bagging as the Core Mechanism

The “Random” in Random Forest comes from two levels of randomization during the training process:

  • Bootstrap Aggregating (Bagging): The algorithm creates several subsets of the original data by sampling with replacement. Each tree is trained on a different subset.

  • Feature Randomness: When splitting a node in a tree, the algorithm only considers a random subset of the available features (columns) rather than all of them. This ensures the trees are diverse and not all relying on the same “strongest” predictor.

The Methodology

  1. Random Sampling: Pick \(N\) random records from the dataset (with replacement).

  2. Tree Building: Build a Decision Tree based on these \(N\) records. At each node, use only a random selection of features to find the best split.

  3. Repetition: Repeat steps 1 and 2 many times (e.g., 100 or 500 trees).

  4. Voting/Averaging: * For Classification: Each tree “votes” for a class (e.g., “Trip Type A” vs “Trip Type B”). The class with the most votes wins.

    • For Regression: The algorithm takes the average of the predictions from all trees.

Why a Forest Instead of a Tree?

A single Decision Tree is prone to overfitting—it learns the “noise” in the training data so well that it performs poorly on new, unseen data.

By aggregating many trees:

  • Variance is Reduced: Errors from individual trees cancel each other out.

  • Robustness: It handles missing values and “outliers” (like an unusually long or expensive trip) better than most linear models.

  • Feature Importance: It can tell you which variables (like “Time of Day” or “Pickup Location”) are the most influential in predicting the outcome.

Mathematical Perspective

If we have a collection of trees \(T_1, T_2, \dots, T_B\), the final prediction \(\hat{f}\) for a regression task is:

\[ \hat{f}=\frac{1}{B} \sum_{b=1}^{B} T_b(x) \]

For classification, it is the mode of the individual tree outputs. The strength of the model is inversely proportional to the correlation between the trees; the more diverse (uncorrelated) the trees are, the better the forest performs.
